**📚 Project 3: Library Management System**
**Description:** A robust management tool for tracking book inventory and student records.

**Key Logic:** 
* Uses a Nested Dictionary as a lightweight database to store book names and their availability status.

**Fine Algorithm:**
* Features a specialized calculation using Floor Division (//).

**Calculation:** 
* Fine is set at ₹40 per 10-day block.
**Workflow:**
* Dashboard: A live display at the top of the output showing Available (✔) and Issued (✖) books.
* Inventory Management: Functions to Add, Issue, and Return books, which dynamically update the dictionary keys
